Checking…

Whisper tiny.en runs on CPU using int8. Dictation transcribes short audio segments locally. Audio exists in memory only. Switching tabs, hiding this page, or pressing Stop releases the microphone.

Your data

Automatic WAV output

Loading output folder…

Choose or change the folder beside Generate. Save as on a take saves one separate copy. History and exported WAVs are managed independently.

Drafts, voices, and completed audio are saved in the local SQLite database. Deleted items go to Trash and can be restored. Nothing is automatically pruned.

Moving from the original UI

Original browser voices stay untouched. Open its Voices tab on the original port, download each reference, and import it here with the transcript. Browser storage cannot be read across ports.
